# 号枢

中文名：**号枢** · 前缀 `haoshu` · 端口 **6300 / 11300**

## 骨架

**业务键入枢纽 → 关系进链接 → 属性进卫星（载荷哈希开版）→ 枢纽-链接-卫星互证**

皮：号卡 / 套餐 / 客户。去皮是 Data Vault，不是营业厅办号、不是积分商城。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6300 → 入湖灌样例 → 枢纽/链接/卫星 → 贯验
```

## 卫星挂错父（05 / 21）

口径全局唯一：**整票失败闭**（甲）+ **隔离名册禁写**。卫星父哈希必须落在对应类型父表且可解
（号卡→枢纽_号卡，套餐→枢纽_套餐，客户→枢纽_客户，订购→链接_号卡套餐）。

任一条错挂 / 不可解，本批枢纽、链接、卫星零增量；错挂证据另路留存，绝不先落后清。

**错挂处置同成败写入隔离名册**（批号、卫星类、卫星键、错误父哈希、期望父类、原因码、处置），
名册与正式表在同一事务内提交：处置成功而名册空不可能；半截失败整票回滚。

**写闸口径（甲）：以隔离名册禁写为准。** 名册未解除前，同卫星类下同卫星键或同错误父哈希的
卫星装载一律拒绝，**即使现查父已可解**。要重灌必须先解除名册行（`POST /api/贯验/错挂名册/解除`）。
这与「以现场父可解为准」（乙：名册不挡写，父可解即允许写、名册分叉由核证暴名）在
「先错挂隔离、后补齐父再灌同键」上结果可区分：甲仍拒绝直至解名册；乙父可解即可写。

- 写闸：`services/装载.py`（先查名册 → 再校验父；全量通过后才统一写出；事务失败整批回滚）
- 规则 / 原因码：`services/父校验.py`（`F-*` 父错误、`G-ROSTER-BLOCK` 名册禁写）
- 名册：`modules/错挂隔离名册`（登记 / 命中禁写 / 解除 / 只读核证）
- 只读贯验：`GET /api/贯验/挂错父`（父哈希、期望父类、残留错挂数、隔离/整票证据 + 名册写闸核证）
- 只读核证：`GET /api/贯验/错挂名册/写闸`（生效禁写、**父已可解仍禁写的分叉**、已解、违规）
- 名册：`GET /api/贯验/错挂名册`；解除：`POST /api/贯验/错挂名册/解除`
- 夹具：
  - `fixtures/卫星错挂父样例.json`（同批一条错挂 + 一条合法套餐升档，甲：全无增量）
  - `fixtures/错挂待补父样例.json`（挂到未建父，登册隔离）
  - `fixtures/错挂后补父样例.json`（补建父枢纽；再灌同键被甲禁写，须先解名册）
- 测试：`PYTHONPATH=backend python backend/tests/test_名册写闸.py`
