# 号枢

中文名：**号枢** · 前缀 `haoshu` · 端口 **6300 / 11300**

## 骨架

**业务键入枢纽 → 关系进链接 → 属性进卫星（载荷哈希开版）→ 枢纽-链接-卫星互证**

皮：号卡 / 套餐 / 客户。去皮是 Data Vault，不是营业厅办号、不是积分商城。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6300 → 入湖灌样例 → 枢纽/链接/卫星 → 贯验
```

## 卫星挂错父（05）

口径全局唯一：**整票失败闭**（甲）。卫星父哈希必须落在对应类型父表且可解
（号卡→枢纽_号卡，套餐→枢纽_套餐，客户→枢纽_客户，订购→链接_号卡套餐）。
任一条错挂 / 不可解，本批枢纽、链接、卫星零增量；错挂证据另路留存，绝不先落后清。

- 写闸：`services/装载.py`（卫星全量校验通过后才统一写入；事务失败整批回滚）
- 规则：`services/父校验.py`
- 只读贯验：`GET /api/贯验/挂错父`（父哈希、期望父类、残留错挂数、隔离/整票证据）
- 夹具：`fixtures/卫星错挂父样例.json`（同批一条错挂 + 一条合法套餐升档，甲：全无增量）
